不对称限时攻防

信标攻防 BeaconGame

一局不对称限时攻防：防守方用短暂窗口埋下信标，进攻方随后限时拆除。信标全灭则攻方胜，撑到时间结束则守方胜。

总览

一句话定义：一局不对称限时攻防。防守方用短暂窗口埋下信标，进攻方随后限时拆除。

设计支柱

不对称但公平

攻防能力镜像互补，胜负取决于执行力而非先天强弱。

时间即压力

放置阶段的“盲”与进攻阶段的“钟”，共同制造倒计时的紧迫感。

随机搅局

事件系统定期打破均势，逼两队不断重新评估局势。

成长正反馈

击杀与破标带来技能升级，让优势方滚雪球、劣势方看到翻盘窗口。

一局怎么玩

一局用两个阶段制造节奏断层：先给守方一段“安心建设”的时间，再突然拉开对抗的闸门。

一局的生命周期

大厅集合 → 加入队列 → 管理员开局 → 放置阶段（守方睁眼埋雷，攻方被蒙眼锁死）→ 进攻阶段（限时拆标 + 事件搅局 + 技能对撞）→ 信标全灭则攻方胜 / 时间耗尽仍有信标则守方胜 → 5 秒结算复原 → 回大厅。

放置阶段（守方窗口）

守方睁眼抓紧埋信标；攻方被蒙眼 + 锁在原地（只能转头），物理上无法靠近。归零前 10 秒有滴答提示。

进攻阶段（对抗期）

闸门拉开：攻方致盲解除、PVP 开启、守方全程发光（等于被标记）。限时拆标开始，事件、技能、HUD 全面激活。

胜负判定

  • 攻方胜：拆光所有信标，或守方一个都没埋（放置结束即判负）。
  • 守方胜：时间耗尽仍有信标残留。
  • 队伍交替分配（先来先攻）避免抱团；对局进行中锁死换边，防止临阵倒戈。

信标系统

信标是整局游戏的唯一胜负轴：守方护住几个点，攻方端掉它们。它把对抗收敛成一个所有人都看得懂的目标。

  • 埋（放置阶段，仅守方）：同一点不能重复埋。信标数量 = 守方的“容错次数”。
  • 护（进攻阶段）：守方多余信标被清空（防偷埋）；守方全程发光（被标记）。
  • 拆（进攻阶段，仅攻方）：破坏信标不掉落物品，信标数 -1；拆到最后一个归零 → 攻方直接获胜。
  • 找：进攻方有“信标指南针”始终指向最近信标；平时信标不发光，仅终局（99% 事件）点亮高亮作为最后冲刺信号。

技能系统

纯靠拆/埋会很快变成“谁人多谁赢”。技能系统给个人一层成长与风格：随对局推进解锁主动技能、选择战斗路线。

  • 开局前选路线：突袭（正面硬刚）/ 干扰（控场）/ 辅助（保队友）。未选按阵营自动分配；辅助只能手动选。
  • 靠击杀解锁（滚雪球）：1 / 2 / 4 杀跨过门槛解锁下一层；每次解锁全队补发补给。
  • 靠事件升级：60% / 80% 事件触发“技能强化”，全队技能层级 +1。
  • 释放：技能是手里一颗“星”，右键即放，有冷却。仅进攻阶段可用。

被动（破标增益）：每次拆掉信标，攻方全队短暂获得力量 + 向前冲量——把“拆标”和“爽感”绑在一起。

对局事件系统

一台按时间自动搅局的机器：到点给全队发东西、或丢个乱子，逼两队不断重新读局势。节奏的“呼吸阀”。

进度 类型 玩家会看到
15%固定小空投：每人 +1 金苹果
30%随机二选一敏捷进攻（攻方加速）/ 防守阳痿（守方虚弱）
50%固定大空投：附魔金苹果 + 不死图腾
60%随机三选一核打击 / 移形换影 / 技能强化
80%随机三选一同上三个再抽一次
99%固定终局总攻：所有信标点亮高亮

“随机三选一”搅局王：核打击（头顶砸下点燃 TNT）、移形换影（随机两两交换位置 10 次）、技能强化（全队技能层级 +1）。BossBar 实时显示“距下次事件还有几秒”。

竞技场与领地边界

对抗需要一个有边界的擂台：太大两队永远碰不上，太小没有走位空间。边界定义“战场在哪”，并负责反作弊。

  • 竞技场是悬空盒子，头顶敞开，四周由领地插件锁定。非成员及外力（末影珍珠/紫颂/活塞/水流）无法越界，立体走位依旧是核心。
  • 底面是虚空：掉到盒子下沿以下会被瞬间送回本方重生点（软惩罚，不计入战绩）。
  • 管理员用“领地木锄”点两个对角框出水平范围；加载时后台自动建/复用对应领地。
