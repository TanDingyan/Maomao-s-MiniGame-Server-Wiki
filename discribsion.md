# Maomao's MiniGame Server

A Minecraft Java server focused on original minigame gameplay.

## About This Server

Every minigame on Maomao's MiniGame Server is designed from scratch.

No copied templates. No recycled mechanics from other servers. Each game mode is built around one core idea: **let players experience rules and challenges they've never seen before in the familiar world of blocks.**

The server was created because the Minecraft minigame scene has long lacked genuinely original content. Too many servers offer reskinned versions of the same classic modes. Maomao's MiniGame Server aims to do something different.

## Original Minigames

Each minigame has its own independently designed maps, mechanics, and win conditions. The design focuses on:

- **Easy to understand, deep to master** — no tutorial needed to start, but real skill is required to excel.
- **Every round feels different** — random elements and dynamic events ensure no two matches play out the same way.
- **Fast-paced and dense** — matches are a comfortable length, perfect for jumping in anytime.

The game list will continue to grow as development progresses.

# Maomao's MiniGame Server

一个专注于原创小游戏玩法的 Minecraft Java 服务器。

## 关于这个服务器

Maomao's MiniGame Server 里的每一款小游戏，都是从零开始设计的。

没有照搬市面上已有的玩法模板，也没有从其他服务器“借鉴”机制——这里的每一个游戏模式，都围绕一个核心设计理念展开：**让玩家在熟悉的方块世界里，体验从未见过的规则和挑战。**

开发这些游戏的初衷，是觉得 Minecraft 小游戏生态中长期缺少真正的原创内容。太多服务器提供的是换皮后的经典模式，而这里想做的是完全不同的事情。

## 原创游戏玩法

每款小游戏都拥有独立设计的地图、机制和胜利条件。游戏设计注重以下原则：

- **规则一眼能懂，操作有深度** — 上手不需要教程，但精通需要真正的技巧
- **每局都有变化** — 随机元素和动态事件确保不会有两局完全相同的体验
- **短节奏、高密度** — 单局时长适中，适合随时来一局

游戏列表会根据开发进度持续更新。
